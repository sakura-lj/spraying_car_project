# 地图质量检查表

建图完成后，至少按以下项目检查一次，再进入导航前定位和 frame 标准化阶段。

- 建图时车辆是否低速、平稳。
- L1RM 初始化时车辆是否保持静止。
- 是否覆盖整个作业区域。
- 是否闭环回到起点附近。
- 点云是否明显漂移、断层或扭曲。
- 地面是否被误标为障碍。
- 树干、墙体、固定设施等障碍是否清晰。
- 是否有动态人、车辆或临时物体进入地图。
- 转换后的 2D 地图障碍是否连通合理。
- 地图分辨率是否适合作业区域和车辆尺寸。
- 地图原点是否记录在 YAML 和 metadata 中。
- metadata 是否填写完整，包括采集地点、时间、参数、已知问题。
- `height_min`、`height_max` 是否记录。
- `inflation_radius` 是否记录。
- point_lio 输出 frame 是否仍为 `camera_init/aft_mapped`，是否已在文档中标注。
- 是否确认当前地图不会直接用于无人值守自动驾驶。
