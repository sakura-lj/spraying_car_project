# 智慧云控果园高效雾化植保车上位机使用文档

本文档说明融合后的单 Flask 应用如何部署、启动、访问和验证。当前系统只需要在 Orange Pi 5B 上运行 `app.py` 一个进程，GPS 采集已经合并为内部线程，Vue 主面板由 Flask 托管。

## 1. 系统入口

- 备用控制面板：`http://OrangePi_IP:5000/`
- Vue 主面板：`http://OrangePi_IP:5000/app`，会进入监控页
- 监控页：`http://OrangePi_IP:5000/app/monitor`
- 控制页：`http://OrangePi_IP:5000/app/control`
- 公网访问：通过 frp 映射后，使用 `http://公网IP:5000/app/monitor` 或 `http://公网IP:5000/app/control`

## 2. 目录说明

```text
upper/
├── app.py                         # 唯一 Flask 主程序：UART + GPS + API + 静态托管
├── start.py                       # 启动 app.py
├── templates/index.html           # / 备用控制面板
├── website/                       # Vue 3 + Vite 主面板源码
├── website/dist/                  # npm run build 后的 Vue 静态产物
├── deploy/frpc.ini                # frp 客户端配置
├── docs/使用文档.md               # 本文档
└── trash/                         # 已移出的旧内容
    ├── GPSup.py                   # 旧独立 GPS/MQTT 上传脚本
    └── webbackend/                # 旧 Flask-MQTT 云端中转
```

## 3. AI iframe 是什么

Vue 页面左侧的“智能问答助手”是一个 iframe，地址是：

```text
http://127.0.0.1:8080/ui/chat/a668fc74f5f490f1
```

它的作用只是把另一个本地问答网页嵌入到主面板里，方便在页面中打开聊天助手。它不参与车辆控制、不发送喷药/速度/方向命令，也不参与 GPS 数据链路。

注意：浏览器访问公网 IP 时，`127.0.0.1` 指的是浏览器所在电脑，不是 Orange Pi。除非用户电脑本地也运行了这个 8080 服务，否则公网访问时这个 iframe 可能空白或连接失败。这不会影响地图、GPS、视频流和车辆控制。

## 4. 首次部署

在 Orange Pi 5B 上进入项目目录：

```bash
cd /path/to/upper
```

安装 Python 依赖：

```bash
python3 -m pip install flask flask-cors pyserial opencv-python numpy
```

安装并构建 Vue 前端：

```bash
cd website
npm install
npm run build
cd ../..
```

构建成功后，`website/dist/index.html` 中的资源路径应为 `/app/assets/...`。

## 5. GPS 串口配置

当前 `app.py` 默认使用：

```bash
GPS_SERIAL_PORT=/dev/ttyUSB0
```

你的 GPS 串口不是 `/dev/ttyUSB0`，启动前需要改成真实设备路径。例如：

```bash
export GPS_SERIAL_PORT=/dev/ttyUSB1
python3 start.py
```

常用检查命令：

```bash
ls /dev/ttyUSB*
dmesg | tail -50
```

如果车辆控制 UART 和 GPS 使用同一个 `/dev/ttyUSB*`，GPS 线程会跳过连接。请确保 GPS 和 STM32 控制串口是两个不同设备。

## 6. 启动系统

在 `upper/` 目录运行：

```bash
export GPS_SERIAL_PORT=/dev/ttyUSB1
python3 start.py
```

启动后 Flask 监听：

```text
0.0.0.0:5000
```

局域网访问：

```text
http://OrangePi_IP:5000/
http://OrangePi_IP:5000/app
http://OrangePi_IP:5000/app/monitor
http://OrangePi_IP:5000/app/control
```

## 7. frp 公网访问

当前 frp 客户端配置在：

```text
deploy/frpc.ini
```

配置内容使用已确认参数：

```ini
[common]
server_addr = 1.15.73.243
server_port = 7000

[spray-car-web]
type = tcp
local_ip = 127.0.0.1
local_port = 5000
remote_port = 5000
```

启动 frp 客户端：

```bash
frpc -c deploy/frpc.ini
```

公网访问方式为 IP 地址访问：

```text
http://公网IP:5000/
http://公网IP:5000/app/monitor
http://公网IP:5000/app/control
```

## 8. 功能验证

查看车辆状态：

```bash
curl http://127.0.0.1:5000/vehicle_status
```

预期包含字段：

```json
{
  "spray_state": 0,
  "speed": 0,
  "direction": 0,
  "turn_position": 51,
  "relay_state": 0,
  "connected": true,
  "gps": {},
  "gps_history": [],
  "gps_connected": true,
  "battery_voltage": 0
}
```

查看 GPS 轨迹数组：

```bash
curl http://127.0.0.1:5000/updateData
```

有 GPS 数据后，每条数据应包含：

```json
{
  "location": [经度, 纬度],
  "speed": 0.0,
  "angle": 0.0,
  "altitude": 0.0,
  "pump_status": {"pump1": false, "pump2": false},
  "timestamp": 1710000000.0
}
```

测试喷药控制：

```bash
curl -X POST http://127.0.0.1:5000/spray_control \
  -H "Content-Type: application/json" \
  -d '{"state": true}'
```

测试速度控制：

```bash
curl -X POST http://127.0.0.1:5000/speed_control \
  -H "Content-Type: application/json" \
  -d '{"speed": 51}'
```

测试方向控制：

```bash
curl -X POST http://127.0.0.1:5000/direction_control \
  -H "Content-Type: application/json" \
  -d '{"direction": 1}'
```

方向值含义：

- `0`：停止
- `1`：前进
- `2`：后退

测试转向控制：

```bash
curl -X POST http://127.0.0.1:5000/turn_control \
  -H "Content-Type: application/json" \
  -d '{"position": 51}'
```

测试紧急停止：

```bash
curl -X POST http://127.0.0.1:5000/emergency_stop \
  -H "Content-Type: application/json" \
  -d '{}'
```

查看视频流：

```text
http://127.0.0.1:5000/video_feed
```

## 9. Vue 主面板使用

打开监控页：

```text
http://OrangePi_IP:5000/app/monitor
```

打开控制页：

```text
http://OrangePi_IP:5000/app/control
```

监控页功能：

- 通信状态：来自 `/vehicle_status`
- 数据包统计：来自 `/updateData`
- 电池电量：优先读取真实 `battery_percentage`；否则按 `battery_voltage` 估算；当前无真实电压时显示 0
- 地图轨迹：来自 GPS 线程写入的 `gps_history`
- 智能问答助手：嵌入本地 8080 问答页面，不参与车辆控制

控制页功能：

- 设备实时状态：来自 `/vehicle_status`
- 启动喷药/停止喷药：调用 `/spray_control`
- 速度滑块：调用 `/speed_control`
- 前进/停止/后退：调用 `/direction_control`
- 转向滑块：调用 `/turn_control`
- 紧急停止：调用 `/emergency_stop`

## 10. 更新前端后重新构建

每次修改 `website/src/` 后，都需要重新构建：

```bash
cd website
npm run build
cd ../..
```

Flask 会自动托管新的 `website/dist/`。

## 11. 常见问题

GPS 一直为空：

- 检查 `GPS_SERIAL_PORT` 是否正确。
- 检查 GPS 模块是否上电。
- 检查 GPS 串口是否被其他程序占用。
- 检查 `vehicle_status` 中的 `gps_connected` 是否为 `true`。

控制命令返回失败：

- 检查 STM32 控制串口是否连接。
- 检查 Orange Pi 是否有串口权限。
- 尝试 `/reconnect`：

```bash
curl -X POST http://127.0.0.1:5000/reconnect
```

公网能打开 `/` 但打不开 `/app`：

- 确认已经执行 `npm run build`。
- 确认 `website/dist/index.html` 存在。
- 确认浏览器访问的是 `http://公网IP:5000/app`。

AI iframe 空白：

- 这是本地 8080 问答服务未运行或公网访问不到导致的。
- 不影响车辆控制和 GPS。
- 如需公网可用，需要把问答服务也部署到 Orange Pi 或改成公网可访问地址。

## 12. 关闭系统

前台启动时按：

```text
Ctrl+C
```

如果使用 systemd 或后台进程管理，请停止对应服务。
